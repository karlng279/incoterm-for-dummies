# Incoterm for Dummies

**Incoterm for Dummies** is an all-in-one learning platform designed to help beginners and students master International Commercial Terms (Incoterms 2020). The application combines educational content, interactive quizzes, unique comparison tools, and practical examples to make learning Incoterms easy and effective.

## 🚀 Features

-   **Comprehensive Education Module**: Detailed explanations of all 11 Incoterms 2020, complete with responsibility diagrams and real-world use cases.
-   **Interactive Quizzes**: Test your knowledge with quizzes ranging from beginner to advanced levels.
-   **Smart Comparison Tool**: Side-by-side comparison of Incoterms to understand key differences in cost, risk, and responsibility.
-   **Selection Wizard**: An interactive guide to help you choose the correct Incoterm for your specific shipping scenario.
-   **Quick Reference**: Handy guides for quick lookups during daily operations.

## 🛠️ Technology Stack

-   **Framework**: [Next.js 16](https://nextjs.org/) (App Router)
-   **Language**: [TypeScript](https://www.typescriptlang.org/)
-   **Styling**: [Tailwind CSS](https://tailwindcss.com/)
-   **UI Components**: [ShadCN UI](https://ui.shadcn.com/)
-   **Icons**: [Lucide React](https://lucide.dev/)
-   **State Management**: React Context
-   **Deployment**: Vercel

## 🚦 Getting Started

### Prerequisites

-   Node.js (v20 or later recommended)
-   npm or yarn

### Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/yourusername/incoterm-for-dummies.git
    cd incoterm-for-dummies
    ```

2.  Install dependencies:
    ```bash
    npm install
    # or
    yarn install
    ```

3.  Run the development server:
    ```bash
    npm run dev
    # or
    yarn dev
    ```

4.  Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
